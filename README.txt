LPN Assistant V1.4 — phone-first prototype

Files:
- index.html: application
- manifest.json: installable web-app metadata
- sw.js: offline cache
- icon-192.png / icon-512.png: app icons

This is a prototype. It does not connect to WFM, Interior Health payroll, or BCNU systems.
Calendar/pay rules are based on the user's configured tracking rules and should be checked against official sources before use for payroll disputes.
